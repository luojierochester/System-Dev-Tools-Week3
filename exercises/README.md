# 第 3 周课后拓展练习

本目录包含 11 个独立、可执行的工程实例：

| 编号 | 目录 | 主题 | 验证重点 |
|---|---|---|---|
| Ex01 | `q13_ext` | Wheel 元数据检查 | 发行名、标签、入口脚本 |
| Ex02 | `q14_ext` | 隔离安装冒烟测试 | 临时 venv、源码目录外运行 |
| Ex03 | `q15_ext` | API 兼容性门禁 | AST、删除公共符号时失败 |
| Ex04 | `q16_ext` | 智能体补丁范围 | 路径归一化、允许列表 |
| Ex05 | `q17_ext` | 智能体任务契约 | 目标、约束、测试、文件范围 |
| Ex06 | `q18_ext` | 有界验证循环 | 超时、重试、JSON 证据 |
| Ex07 | `q19_ext` | Issue 质量门禁 | 环境、复现、期望、实际 |
| Ex08 | `q20_ext` | Review 质量门禁 | 级别、风险、动作、验证 |
| Ex09 | `q21_ext` | PyTorch 可复现性 | 两次训练逐张量一致 |
| Ex10 | `q22_ext` | 梯度诊断 | 梯度范数、裁剪、有限值 |
| Ex11 | `q23_ext` | 检查点往返 | CPU 加载、预测完全一致 |

全部实例由仓库根目录的 `scripts/verify_all.ps1` 统一执行。
